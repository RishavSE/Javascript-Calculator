<h2 align="center">📌 Overview</h2>

JavaScript Calculator is a beginner-friendly calculator application designed to perform everyday arithmetic operations through a clean and intuitive interface.

Built using HTML5, CSS3, and vanilla JavaScript, the project demonstrates fundamental frontend development concepts, including DOM manipulation, event handling, and interactive UI updates.

In addition to the web version, an Android APK is available for users who prefer to install and use the calculator on their Android devices.

<h2 align="center">✨ Features</h2>

✔ Addition, subtraction, multiplication, and division  
✔ Responsive calculator interface  
✔ Clear and reset functionality  
✔ Real-time input and result display  
✔ Simple and easy-to-use button layout  
✔ Lightweight frontend implementation  
✔ Browser-based usage without a build step  
✔ Android APK available through GitHub Releases  

<h2 align="center">🧮 Calculator Operations</h2>

The calculator supports basic arithmetic operations:

- **Addition (+):** Add two numbers.
- **Subtraction (−):** Calculate the difference between numbers.
- **Multiplication (×):** Multiply numbers.
- **Division (÷):** Divide one number by another.
- **Clear / Reset:** Clear the current input and start a new calculation.

<h2 align="center">🚀 Getting Started</h2>

You can run the web version in two simple ways.

### Option 1: Open Directly in a Browser

**1. Clone the repository**

```bash
git clone https://github.com/rishavSE/Javascript-calculator.git
```

**2. Navigate to the project directory**

```bash
cd Javascript-calculator
```

**3. Open the application**

Locate `index.html` and double-click it to open the calculator in your default browser.

Alternatively, right-click the file and select your preferred browser.

### Option 2: Run with VS Code Live Server

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

The calculator will open in your browser, and Live Server will automatically reload the page when you save changes.

### Installation Steps

1. Open the [GitHub Releases page](https://github.com/rishavSE/Javascript-calculator/releases).
2. Select the latest release.
3. Under **Assets**, download the `.apk` file.
4. Open the downloaded APK on your Android device.
5. If prompted, allow installation from that source in your Android settings.
6. Follow the installation instructions to install the application.

**Note:** Android may display a security warning when installing an APK downloaded outside the Play Store. Install it only if you trust its source.
